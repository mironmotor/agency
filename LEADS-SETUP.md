# Приём заявок — что осталось подключить

Сайт статический (GitHub Pages), своего сервера нет. Поэтому заявка уходит в
Google Apps Script, а он пишет строку в Google-таблицу и шлёт письмо.
Бесплатно, без лимитов, без посредников.

**Метрика уже подключена:** счётчик `111977007`, вебвизор и карта кликов
включены, цель `lead` вызывается при успешной отправке формы.
Осталось создать саму цель в кабинете (шаг 2).

## 1. Таблица заявок

1. Новая Google-таблица → назвать «LTF — заявки».
2. `Расширения → Apps Script` → удалить всё, вставить код ниже → сохранить.
3. `Развернуть → Новое развёртывание` → тип **Веб-приложение**:
   - «Запуск от имени»: **Я**
   - «У кого есть доступ»: **Все**
4. Google попросит разрешения — выдать (скрипт пишет в твою же таблицу).
5. Скопировать адрес вида `https://script.google.com/macros/s/…/exec`
   и прислать мне — вставлю в `index.html` в `const LEAD_ENDPOINT = '';`.

```javascript
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(['Дата', 'Имя', 'Контакт', 'Ответы квиза', 'Результат', 'Страница', 'Источник']);
  }
  let d = {};
  try { d = JSON.parse(e.postData.contents); } catch (err) { d = e.parameter || {}; }
  sheet.appendRow([
    new Date(), d.name || '', d.contact || '', d.answers || '',
    d.result || '', d.page || '', d.ref || '',
  ]);

  // Письмо сразу — иначе заявку увидишь, только когда откроешь таблицу.
  MailApp.sendEmail({
    to: Session.getEffectiveUser().getEmail(),
    subject: 'LTF: заявка от ' + (d.name || 'без имени'),
    body: [d.name, d.contact, d.answers, d.result, d.page].join('\n'),
  });

  return ContentService.createTextOutput('ok');
}
```

## 2. Цель в Метрике

`Настройка → Цели → Добавить цель` → тип **JavaScript-событие** →
идентификатор ровно `lead`. По ней Директ считает стоимость заявки.

## 3. Проверка перед включением рекламы

- Пройти квиз до конца, отправить форму со своим номером.
- Строка появилась в таблице? Письмо пришло?
- В Метрике `Отчёты → Конверсии` через полчаса видно достижение цели.

Без этих трёх галочек рекламу включать нельзя: бюджет открутится, а заявки
осядут в пустоте.
