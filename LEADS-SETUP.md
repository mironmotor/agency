# Приём заявок и аналитика — что подставить

Сайт статический (GitHub Pages), своего сервера нет. Поэтому заявка уходит в
Google Apps Script, а он пишет строку в Google-таблицу. Бесплатно, без лимитов,
без сервисов-посредников.

## 1. Таблица заявок (5 минут)

1. Создай Google-таблицу, назови «LTF — заявки».
2. `Расширения → Apps Script`, вставь код ниже вместо содержимого файла.
3. `Развернуть → Новое развёртывание → Веб-приложение`:
   - «Запуск от имени»: **Я**
   - «У кого есть доступ»: **Все**
4. Скопируй выданный адрес вида `https://script.google.com/macros/s/…/exec`.
5. В `index.html` найди `const LEAD_ENDPOINT = '';` и вставь адрес в кавычки.

```javascript
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(['Дата', 'Имя', 'Контакт', 'Ответы квиза', 'Результат', 'Страница', 'Источник']);
  }
  let d = {};
  try { d = JSON.parse(e.postData.contents); } catch (err) { d = e.parameter || {}; }
  sheet.appendRow([
    new Date(), d.name || '', d.contact || '', d.answers || '',
    d.result || '', d.page || '', d.ref || '',
  ]);

  // Уведомление на почту — чтобы заявку увидеть сразу, а не когда откроешь таблицу.
  MailApp.sendEmail({
    to: Session.getEffectiveUser().getEmail(),
    subject: 'LTF: заявка от ' + (d.name || 'без имени'),
    body: [d.name, d.contact, d.answers, d.result, d.page].join('\n'),
  });

  return ContentService.createTextOutput('ok');
}
```

## 2. Яндекс.Метрика (2 минуты)

1. Заведи счётчик на `mironmotor.github.io` (или возьми существующий).
2. В `index.html` замени `00000000` на номер счётчика — **в двух местах**
   (`window.YM_ID` и адрес картинки в `<noscript>`).
3. Цель уже прописана в коде: при успешной отправке формы вызывается
   `reachGoal('lead')`. В Метрике создай цель типа «JavaScript-событие»
   с идентификатором **lead** — по ней считается стоимость заявки.

## 3. Проверка перед запуском рекламы

- Пройди квиз до конца, отправь форму со своим номером.
- Строка появилась в таблице? Письмо пришло?
- В Метрике `Отчёты → Конверсии` через полчаса видно достижение цели.

Без этих трёх галочек рекламу включать нельзя: бюджет открутится, а заявки
осядут в пустоте.
